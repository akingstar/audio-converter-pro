# AUDIO CONVERTER PRO

A free browser-based audio converter.

## Features
- Batch audio conversion
- MP3, WAV, FLAC, M4A, AAC, OGG, OPUS and AIFF options
- Audio bitrate and sample-rate settings
- Mono and stereo options
- Audio normalization
- FFmpeg WebAssembly processing in the browser

## Hosting
This project is designed for free GitHub Pages hosting.

## Privacy
Audio processing is performed in the browser. FFmpeg libraries are loaded from public CDNs.

## Usage
1. Open the website.
2. Select audio files.
3. Choose output format and quality.
4. Start conversion.
5. Download converted files.
